# Capstone Spring Boot Banking Microservice on AWS with Jenkins Docker and Ansible

**Project type:** Cloud/DevOps implementation project documented in my portfolio.

## Implementation summary

I completed a capstone deployment of a Spring Boot banking microservice on AWS using Jenkins, Docker and Ansible. The project brought application delivery and infrastructure automation together in one workflow. I prepared the banking microservice repository and build configuration. I configured the Jenkins workflow for code retrieval, Maven builds and the test stages included in the project. I built the Docker image and used the configured Jenkins and Ansible steps to prepare or deploy to the target. I validated connectivity, container status and the application endpoint. I preserved pipeline, Dockerfile and playbook evidence to show which tool performed each task. The project output consisted of a deployed Spring Boot banking microservice with an integrated pipeline and runtime validation. Banking functionality is limited to the endpoints implemented; this does not establish a production financial system. This work demonstrates how application and infrastructure automation can be connected. The business opportunity is a repeatable release process and clearer troubleshooting across build, packaging and deployment stages. The capstone provides a practical delivery pattern for a containerized Java service. It demonstrates how code retrieval, build tooling, image packaging and deployment automation work together, with endpoint checks confirming runtime behavior.
